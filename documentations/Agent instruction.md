# Agent Instruction

Before starting any work or adding any feature:

1. Read the documentation in `documentations/` first.
2. Analyze the relevant docs and audit notes so the work follows the documented architecture, module rules, and known issues.
3. Start editing only after the documentation context is understood.
4. After finishing the work, update the documentation with what changed, including any new behavior, known limitations, or follow-up tasks.
5. Push the completed work to the GitHub repository.
6. If the work requires a database change, create the required migration file and apply the migration.
